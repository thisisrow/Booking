# PalgharCity48

**Domain**: [https://www.palgharcity48.com/](https://www.palgharcity48.com/)

PalgharCity48 is a comprehensive web application designed to provide users with a seamless experience for exploring and booking luxury accommodations, water parks, villas, and properties in Palghar, Virar, and Mumbai.

## Features

### 1. Accommodation Listings
- **Resorts, Villas, and Water Parks**:
  - Browse through a curated list of resorts, villas, and water parks.
  - Each listing includes details like name, location, price, rating, images, and amenities.

### 2. Property Listings
- **Real Estate Properties**:
  - Explore properties such as apartments, houses, and commercial spaces.
  - Each property includes details like price, bedrooms, bathrooms, area, and features.

### 3. Booking System
- **Booking Details Page**:
  - Book accommodations or properties by providing personal details, selecting dates, and specifying the number of adults and children.
  - Includes a cost breakdown and optional pickup service.
  - Integrated with Razorpay for secure online payments.

### 4. Context-Based State Management
- **Centralized Data Management**:
  - Contexts like `WaterContext`, `PropertiesContext`, and `TourismContext` manage data for resorts, properties, and tourism spots.
  - Custom hooks provide easy access to context data.

### 5. Social Media Integration
- **Social Feed**:
  - Displays posts, likes, comments, and YouTube videos to engage users.
  - Includes links to Instagram and YouTube for further interaction.

### 6. Contact and Collaboration
- **Contact Us Page**:
  - Send messages via a contact form integrated with EmailJS.
  - Includes quick links to WhatsApp for direct communication.
- **Collaboration Opportunities**:
  - Influencers can apply for partnerships through a dedicated collaboration page.

### 7. Tourism Information
- **Tourism Spots**:
  - Explore popular tourist destinations with details like attractions, best time to visit, and weather.

### 8. Theming and Accessibility
- **Dark Mode Support**:
  - Toggle between light and dark themes using the `ThemeToggle` component.

### 9. Responsive Design
- **Mobile-Friendly UI**:
  - Fully responsive design ensures a seamless experience across devices.

### 10. Admin and Branding
- **Admin Information**:
  - Highlights the founder and team behind the project.
- **Branding**:
  - Includes social media links, a custom favicon, and structured metadata for SEO.

### 11. Technology Stack
- **React and TypeScript**:
  - Ensures a scalable and type-safe codebase.
- **Vite**:
  - Provides a fast development environment.
- **Tailwind CSS**:
  - Enables rapid UI development with utility-first CSS.

## Getting Started

### Prerequisites
- Node.js and npm installed on your system.

### Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd Booking
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application
1. Start the development server:
   ```bash
   npm run dev
   ```
2. Open your browser and navigate to `http://localhost:3000`.
